# UI 设计准则

本文件只是摘要。完整规则以 [设计系统](design-system.md) 为准，各屏布局见 [玻璃 PWA 规范](ui-glass-spec.md)，施工见 [分步施工手册](ui-build-steps.md)。冲突时以设计系统为准。

- 优先适配 iPhone 独立 PWA，验证 320 / 375 / 390 / 430 宽及横屏、安全区与键盘弹出；桌面（≥1024）铺满整屏，不做居中窄版。
- 深色背景与玻璃控制层，每屏玻璃层不超过四层；减少透明度或不支持 backdrop-filter 时用不透明深色底。
- 数字使用本地 JetBrains Mono，中文使用系统字体。图标控件保留 aria-label、键盘焦点和至少 44px 命中区。
- 禁止整页双击及双指缩放，保留正常滚动、表单输入和时间轴业务手势。全局文本不可选，输入区恢复选择。
- 保留必要的直播/回放状态、时间、选择项和错误，不只靠颜色表达状态。
- 状态以实际播放器为准，连接中、暂停、结束和失败不能标成正在直播。
- 播放位置、请求定位和导出范围是不同语义；切换预览不得清除用户已选导出范围。
- SDK 未知时间精度必须如实标示，不能推算成精确帧时间。
- 测试全绿之外，实际启动服务验证目标交互与浏览器 console；桌面模拟不能代替 iPhone PWA 与真机媒体验收。
