# Local Windows executable build

This first distribution contains source only. No old EXE, Actions artifact or release has been reviewed or included, and no build/release workflow is configured.

The local SEA and portable build entrypoints remain available for a separately reviewed binary release. See [cross-platform builds](cross-build.md) for commands and platform limits. A local build can download tools and dependencies; verify their licenses and the resulting artifact before redistribution. The executable does not guarantee bundled FFmpeg/ffprobe. This snapshot has not validated Windows executable packaging, signing or runtime behavior.
