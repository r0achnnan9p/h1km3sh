# 录像工作台各屏规格

设计令牌、弹层容器、iOS 视口策略和快捷键集中在[设计系统](design-system.md)。本文件说明每个入口的布局、状态和操作。

## 应用启动与导航

| 入口 | 手机 | 桌面 |
|---|---|---|
| 启动、初始设置、解锁 | 状态、密码表单和重试操作在安全区内。初始化码与新密码分别标注，校验失败保留就地提示 | 同一表单居中显示，输入宽度便于阅读 |
| 四个工作区 | 底部通栏依次为回放、成片、任务、设置。每项有图标和中文名称。64px 控件区下方叠加真实底部安全区 | 1024px 起使用带品牌和中文标签的 160px 左侧栏。选中项可见，正文随可用宽度展开 |
| 状态与更新 | 连接中断时保留最后状态并提示重连。页头“重新加载应用”保留当前页。设置和账号详情的刷新只更新就近数据 | 与手机相同，任务或成片更新保留各列表位置 |

手机底栏支持点按，也支持横向拖动预览；释放后再切页。短横屏回放或进入全屏时收起普通导航。

## 录像回放

1. 页头显示“录像回放”和重新加载按钮。来源、录像机／镜头和日期在播放器上方选择，日期左右的按钮逐日移动。无镜头、未选通道、查询中、读取失败、当日无录像与可播放分别呈现对应状态。
2. 画面用 `object-fit: contain` 完整显示。播放器状态随真实的直播、回放、等待、暂停、结束或错误更新。只有可以返回直播时才显示对应动作。
3. 播放／暂停、前后 10 秒、当前位置、声音与全屏紧邻时间尺。入点、出点各自提供标记按钮和可直接输入的时间；清除、片段时长、导出同处选段区。窄屏按空间换行，短屏允许正文滚动到底。
4. 桌面回放占满剩余高度和宽度。操作仍使用相同的一组 DOM 和状态，视频使用操作区以外的空间；正文不受手机最大宽度限制。

### 时间尺、选段与导出

- 全日、1 小时、5 分钟、30 秒四档可以直接切换，初始全天。只有一条可交互的时间尺，显示覆盖、缺口、当前指针和选区。
- 全天按绝对位置粗选。局部窗口固定中心指针，用一次拖动的完整相对位移计算整秒候选，松手仅提交最终定位。再次按下可从新位置继续拖动，避免慢拖过程中逐次取整。日期边界保留中心，越界与未来时段变暗，录像和缺口按实际比例裁剪。
- 切档保留日期、位置和入出点。前后跳转和长按步进始终为 10 秒，取消手势、切源或换日会取消未提交定位。时间尺获焦后的键盘微调见[设计系统](design-system.md)。
- 只有标记或编辑时间才修改导出边界，出点至少晚于入点 1 秒。打开定位／边界编辑器时同步选中已有时间，后续输入保留光标。精确到秒与视频精确到帧是两个独立能力。
- 含录像中断时，导出确认逐条列出缺口的起止时间和时长，跨午夜标记次日；允许取消或明确跳过缺口。提交成功留在回放页，出现可前往任务的提示，下一次进入任务页优先定位刚提交的任务。

### 横屏与全屏

主要验收尺寸为 430×932 和 932×430 CSS 像素。短横屏回放及原生／CSS 全屏时，来源与日期贴近顶部安全区，播放、时间尺、选段与导出组成底部控制面。较窄横屏按行换位；额外错误或控件超出高度时，控制面内部可滚动。

闲置约 2.5 秒自动隐藏，暂停也可收起。点按画面可立即隐藏，隐藏后的第一次点按只唤醒。手动隐藏保持到下一次明确输入。拖动、长按、弹层、输入、可见键盘焦点及提交期间保持相关控件可操作。普通竖屏和桌面收起控件时，视频可使用释放的空间；退出全屏后保留比例、位置和边界。

## 成片库

- 页头提供文件名搜索，排序按钮标明“最新在前”或“最早在前”。汇总展示文件数与总大小；搜索时显示匹配数／总数和匹配文件的总大小。无文件、无匹配结果各有相应说明。
- 手机使用带缩略图、文件名、大小、日期和上传状态的列表。长文件名最多显示两行，详情展示全名。点开详情后播放同一份成片；支持改名、下载／系统分享、上传到 189 或 B站、删除确认。待核实上传与未完成改名可从对应详情进入恢复流程。
- 桌面使用自适应卡片网格，提供原地播放、改名、下载、选择上传平台和更多操作。播放器与操作按钮可从键盘访问。
- 忙碌、上传中、已上传、待核实、上传未配置分别反映可执行的操作。上传确认显示文件和目标，删除说明不可逆后果。下载／分享入口按浏览器能力提供相应方式。
- 与任务列表共用分页和滚动锚点逻辑，首批 20 条，下滚逐批增加；实时刷新避免替换正在播放或编辑的控件。

## 任务中心

手机以导出／上传两个页签切换，显示活跃数量。桌面并列显示两个可独立滚动的任务列表。各列表先展示待核实与进行中任务，再展示历史；同组按创建时间倒序，完成状态变化不改写创建时间。已归档操作依据服务端状态呈现。

- 活跃任务显示阶段、已传／总量、进度、可用的速度与预计剩余时间，允许取消的任务才显示对应动作。历史项可直接阅读。失败、等待确认和已完成都有文字或其他可访问的状态信息。
- 189 结果未知时，从原记录核实、移除、恢复或明确确认重试。操作中防止重复提交，失败时给出可重试状态，保留历史与文件关联。未配置或账号需重新连接时引导至对应设置。
- `public/task-presentation.js` 统一传输读数。速度按十进制 bps／Kbps／Mbps／Gbps、约三位有效数字显示。可用累计字节根据服务端时间戳采样，默认窗口 5 秒；服务端已平滑的速度直接使用。缺少新采样时显示未知，剩余时间需要可靠的总量、已传量和正速率。重复 SSE 不生成速度样本。
- 在列表之间切换、加载更多或收到 SSE 时保留滚动锚点；只有刚提交任务的显式定位优先。提交提示约 3 秒后隐藏，键盘焦点仍在提示内时延迟撤下。

## 设置

| 分组 | 内容与操作 |
|---|---|
| 来源 | 海康录像机列表、添加／编辑、测试连接、读取通道和确认删除。MediaMTX 回放地址、自动发现与手动补充通道、名称与录像机关联、抓拍核对、删除映射 |
| 上传账户 | 189 行以云图标标识。189 和 B站都提供连接状态、检测、扫码、替换连接、手机确认、断开确认和重新登录。B站详情还提供封面预览、文件选择／拖放及保存反馈 |
| 存储 | 缓存用量与清理确认，说明成片和未完成分片的保留范围 |
| 安全 | 根据当前服务配置提供密码更新与退出登录确认 |

手机通过行进入二级详情。桌面从录像机概览开始，点击分类在右栏切换详情，并标记当前行。手机详情与桌面面板复用渲染函数，编辑表单、账号连接和确认继续复用原生弹层。检查准备模式、配置加载失败、未保存退出以及配置写入冲突后保留输入的流程。

## 独立入口

| 页面 | 规格 |
|---|---|
| OAuth 摄像头授权 | 显示应用身份、授权用途、已验证的返回域名和密码表单。失败与限流给出重新连接的方式。固定样式经 CSP 哈希允许 |
| 签名录像结果 | 手机先列任务、进度与时间范围，再列文件。桌面两栏并列。进行中持续查询，终态显示最近更新时间；网络失败给出重试状态 |
| MCP 媒体卡 | 紧凑标题、状态、有效文件入口。已生成视频内联播放，截图提供原图链接，批量成片逐文件列出。保留签名链接与宿主允许来源校验 |

## 验收入口

- 使用仓库的[合成控制台](../scripts/console-fixture.README.md)分别验收正常、空、失败、未登录和首次设置，动手走完选段导出、成片详情、任务处理、设置编辑／取消和账号状态切换。合成数据可以验证 UI，不提供真实设备或第三方上传结果。
- 手机检查 320、375、390、430px 及短横屏。桌面检查 1024、1440、1920px 的导航、面板、键盘与长列表。保留 430×932／932×430 的主验收样式，较大屏幕用同一套规则展开。
- 真实 iPhone 从主屏启动检查状态栏渐隐、安全区、软键盘、全屏视频、系统分享与旋转。实际 NVR／MediaMTX 媒体行为与上传提供商验证单独记录。
