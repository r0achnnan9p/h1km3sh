# UI 改版规格（玻璃质感 · 自用 PWA）

本文件是 Web 控制台（`public/console.js` + `console.css`）**各屏布局与尺寸**的依据。通用规则（Token、组件、交互、断点、文案、禁止清单）见 [design-system.md](design-system.md)，两者冲突以 design-system 为准。
视觉参照：`docs/design/*.png`（由画布导出）。数值以本文为准，截图只用于对照观感。

## 1. 总则
- 主场景是 iPhone 主屏 PWA（standalone）。桌面（≥1024）有独立布局，见 §3.10，必须铺满整屏。
- 深色底 + 玻璃浮层。玻璃只用于"浮在视频/背景上的控制层"：顶部胶囊、面板、导出栏、底部导航、提示条。同屏玻璃层 ≤ 4。
- 图标优先，文字极少；数字（时间、速度、大小）一律等宽字体。
- 全局禁用文本选择：`-webkit-user-select:none; user-select:none; -webkit-touch-callout:none; -webkit-tap-highlight-color:transparent`；input/textarea 单独放开。
- 所有可点元素 `touch-action: manipulation`，最小触控 44px，主按钮 56px 高。
- 一次点击必须有确定结果和即时反馈，不依赖悬停。

## 3. 各屏规格（iPhone 14 Pro Max 为主要验收目标）
### 3.1 回放页（Main；2026-10-17 选定的原型 3）
- 手机目标为 CSS 视口 **430×932 竖屏 / 932×430 横屏**；继续覆盖 320、375、390 宽。尺寸用于验收，不作为应用高度常量。布局使用既有 `--app-viewport-height`、`--safe-*` 与有界状态栏渐隐避让。
- 采用“观看 / 选段”两种模式，切回观看只收起选段操作，保留日期、通道、入点和出点。选段模式仍能观看、播放和定位。
- 竖屏自上而下：项目名与统一刷新 → 来源 / 通道 / 日期 → 视频 → 紧凑播放控制与当前位置 → 单一时间轴 → 模式切换 → 选段编辑区。所有正常选段操作应在目标设备的一屏可达，底栏与安全区独立占位。
- 视频取剩余空间、允许收缩；保持 `object-fit: contain`，不裁切录像。取消四角重复播放、直播、静音、全屏按钮，这些动作放入一处紧凑控制栏。
- 播放控制保留播放 / 暂停、前后 10 秒、回到直播、静音和全屏。日期前后切换与日期显示同组，按钮图标至少 24px，触控区域至少 44×44px。
- 单一时间轴保留全天覆盖、当前指针和选区；压缩可视刻度与录像段条，实际拖动命中高度仍至少 44px。精调沿用现有离轨拖动行为。
- 选段编辑区：入点 / 出点按钮并排，单击以当前位置标记；精确输入和清除紧邻边界设置，时长与导出在同一操作区。手机不再为输入与清除另占一整行后再追加独立导出栏。操作名清晰，时间使用等宽字体，按钮最小高度 44px。
- 不再在首页显示独立缺口警告按钮。点击导出时快速确认缺口，每条只显示**开始时间 → 结束时间、持续时间**；同日不重复显示日期。用户可以取消或明确接受中断后导出。
- 页面高度有界，视频让出操作所需空间；极小视口、系统放大或错误重试内容超出时，只让正文容器滚动，所有操作仍可达，禁止被底部导航遮盖。
### 3.2 拖动出点（Trim 状态）
- 拖动把手时：把手加粗到 16、光晕增强；非拖动的另一把手降为 55% 不透明。
- 视频上方居中显示玻璃时间牌：出点/入点图标 + 36px 等宽时间。
- 把手上方出现放大镜：直径 112 圆形玻璃，内含 1 秒级刻度、居中强调色竖线、当前秒时间 16px；下方带指向把手的小尖角。放大镜中心与把手同 x。
### 3.3 横屏与全屏（Landscape / Fullscreen）
- 视频铺满可见区域，画面保持完整；顶部来源 / 通道 / 日期与底部控制面均位于系统安全区内。手机横屏默认收起底部导航，回到竖屏恢复同一页。
- 观看模式：一处紧凑的底部操作面包含播放、前后 10 秒、时间、静音、全屏、模式入口和细时间轴；去掉中部常驻的大面板与四角按钮。
- 选段模式：在同一底部操作面展开入点 / 出点按钮、精确输入、清除、片段时长和导出；横屏仍可直接按当前播放位置设置边界，不要求先退出横屏。
- 无输入时，整个控制面和顶部选择行一同自动隐藏，轻触画面重新显示；隐藏控件不能继续命中或取得焦点。拖动、长按步进、弹层和提交处理中保持可操作，结束后重新计时。
- 进入精确输入或中断确认继续使用共用弹层；原生全屏时弹层、提示与时间精调层必须属于全屏子树。超短横屏的错误内容允许操作面内部滚动，不越过安全区。
### 3.4 提交提示（Toast）
点导出/上传后**不跳转**。导出栏上方弹玻璃提示条（高 64，圆角 32）：类型图标（下载/云）+ 右下绿色对勾角标，等宽时间范围，右侧 48×48 箭头按钮（点击才去任务页）。3 秒自动消失，条底部有 3px 倒计时线。同时导出按钮短暂变绿色对勾，底部"任务"图标出现数字角标。
### 3.5 任务页（导出 / 上传）
- 顶部固定：双页签玻璃分段（导出=下载图标，上传=云图标），各带进行中数量角标（导出用强调色，上传用琥珀色）；右侧清除已结束按钮（垃圾桶，60×60）。
- 中间列表滚动区（顶部页签和底部导航固定），底部 44px 渐隐遮罩。
- 列表顺序：需要处理的（上传需验证：琥珀色边框卡片，右侧箭头）→ 进行中的卡片 → 按日期分组的历史（今天/昨天/MM/DD）。
- **无折叠、无"更早"入口**：首次渲染 20 条，滚动到底（IntersectionObserver）再加 20 条，直到没有更多。SSE 更新时必须保留滚动位置和已加载条数，不得整表重置。
- 历史行高 64：状态圆 36（✓ 绿 / ! 红）+ 等宽时间范围 + 次行 `通道 · 时长`（上传行用云/B站图标 + 大小）+ 右侧完成时间；失败行右侧为 48×48 重试按钮（红色）。
- 进行中卡片：旋转环 + 时间范围 + 次行（已传/总量，如 `94/150 MB`）+ 右侧百分比 22px + 取消。进度条高 10，渐变填充 + 微光。其下一行：左 `闪电图标 速度 数值+单位` + 56×20 最近速度小曲线，右 `时钟图标 剩余时间 m:ss`。
### 3.6 设置页
四组玻璃列表，行高 64：图标方块 36 + 名称 + 右侧状态/数值/箭头。
1. 来源：`海康录像机`（数量）、`MediaMTX`（通道数；回放地址并入其二级页，不再单独成行）。
2. 上传账户：`189`（天翼云盘，目前只接这一个）、`B站`；状态用图标（✓ 绿 / ⚠ 琥珀）。
3. 缓存：磁盘图标 + 大小 + 右侧红色清理按钮（点击需二次确认）。
4. 安全：`密码`、`退出登录`（红色）。
长说明、封面设置等全部放进点开的二级底部弹层（沿用 `openDialog`）。
### 3.7 底部导航
四项纯图标：回放、成片、任务、设置。按 2026-10-09 用户再次确认的交互原型，手机改为贴底通栏，控件区高 64，底部另加系统安全区，背景 `--bg`，只有顶部 `--line`，无悬浮间隙、外圆角、玻璃阴影。选中背景复用 `--tint` 和 `--radius-field`，图标 26、命中区至少 44，并有强调色下划线；拖动指示仍跟随手指，释放才切页。桌面侧栏保持原规格。

### 3.8 成片页（手机）
- 顶部：搜索框（玻璃 L2，52 高胶囊，搜索图标 + 输入）+ 右侧 52 圆形排序按钮（最新/最早切换）。
- 其下一行汇总：成片图标 + `数量 · 总大小`（等宽 13px，`--muted`）。
- 列表：一块玻璃列表，行高 88：缩略图 112×63（圆角 12，右下等宽时长角标；上传中底部 3px 强调色进度条）+ 名称（16/600，单行省略）+ 次行 `大小 · 日期` 和状态小图标（189 云 ✓、B站 ✓ 为绿色，待核实为琥珀 ⚠）+ 右侧 44 “更多”按钮。底部 44px 渐隐。
- 点一行打开 §3.9 详情弹层；“更多”直接打开同一弹层。不在列表里内联播放。
- 首屏 20 条，滚动到底再加载，与任务页同一套分页与保位逻辑。
### 3.9 成片详情弹层（手机底部弹层）
- 抓手 → 16:9 播放区（圆角 22，中央 64 玻璃播放按钮，右下时长）→ 名称 19/600 + 次行 `大小 · 日期时间`，右侧 48 改名按钮（铅笔）。
- 上传状态小列表（凹槽底，行高 56）：`189`、`B站` 各一行，进行中显示细进度条 + 百分比，完成显示绿色 ✓，未上传显示“—”。
- 底部四个等宽 64 高按钮（仅图标）：下载、上传到 189、上传到 B站、删除（珊瑚红，二次确认）。已上传或正在上传的目标按钮置灰。
### 3.10 桌面（≥1024，铺满整屏）
通用：左侧悬浮竖向导航（L2，宽 72，四个 56 图标，`title` 提示，任务角标），内容区占满剩余宽度，**不设 max-width**，外边距 24、栏间距 16。
1. 回放：采用与手机相同的观看 / 选段模式和同一组控件，不再把入出点与来源搬入独立侧栏。顶部来源 / 通道 / 日期；视频横跨正文全宽并占剩余高度；下方是一处播放控制、细时间轴和模式切换，选段操作横向紧凑排列。
   - 回放页整屏高度不滚动，视频区允许收缩，`object-fit: contain`；1024 / 1440 / 1920 宽都使用可用正文宽度。
   - 日期前后切换与日期同组。时间轴仍支持鼠标悬停、现有键盘定位和离轨精调；操作与手机共用状态和节点。
   - 全屏时复用 §3.3 的底部控制面与安全区规则；观看和选段模式均可进入全屏，切换模式不会清除选段。
2. 任务：导出、上传两栏并排（各占一半），不用页签。每栏：标题行（图标 + 标题文字 + 角标 + 清除按钮）→ 待处理卡（上传需验证）→ 进行中卡 → 历史列表（行高 60，时间范围、元信息、完成时间同一行）。两栏各自独立无限滚动。
3. 成片：工具行（搜索框 360 宽，`/` 键聚焦；排序；右侧汇总）+ 卡片网格 `repeat(auto-fill, minmax(260px, 1fr))`，屏幕越宽列越多。卡片（L2，圆角 24）：16:9 缩略图（左上上传状态，右下时长，悬停出现中央播放按钮，点击原地播放）+ 名称/次行 + 常驻三个 40 按钮：下载、上传（选目标）、更多（改名 / 删除）。
4. 设置：主从布局。左栏 `clamp(320px,24vw,400px)` 为与手机相同的分组列表（行高 56，选中项左侧强调线）；右栏详情面板占满剩余宽度，内容与手机二级弹层**同一个渲染函数**。录像机详情：标题 + 添加按钮 → 设备页签（状态点 + 名称 + IP）→ 表单 `repeat(auto-fill, minmax(240px,1fr))`（名称、主机地址、HTTP 端口、RTSP 端口、用户名、密码）→ 底行：删除（危险）…… 通道数状态、测试、保存。
5. 桌面所有弹层（确认、上传目标选择）用居中模态，不用底部弹层。
6. 快捷键见 design-system §9。

## 4. 速度与剩余时间
- 速度单位用**比特**，进位 1000：`bps / Kbps / Mbps / Gbps`；三位有效数字（≥100 取整，≥10 一位小数，否则两位）。大小用**字节**（MB）。
- 参考实现：
```js
const fmtBps = bps => {
  const units = ['bps', 'Kbps', 'Mbps', 'Gbps'];
  let i = 0, v = bps;
  while (v >= 1000 && i < units.length - 1) { v /= 1000; i++; }
  return { v: v >= 100 ? v.toFixed(0) : v >= 10 ? v.toFixed(1) : v.toFixed(2), u: units[i] };
};
```
- 速度取最近 3–5 秒滑动平均，不显示瞬时值；剩余时间 = 剩余字节 × 8 / 平均速度，同样平滑。需先确认任务数据里有已传字节数，没有就由前端按进度差值估算。

## 5. 时间轴交互约束
- 窗口跟手指移动，指针不动；松手时**只用最后一次 pointermove 的位置**，不读 pointerup 坐标。
- 缩放档位 30s/5m/1h/24h，默认 5m；5m 档约 0.8 秒/像素。
- 把手拖动沿用现有边界约束（入点<出点，至少 1 秒）。

## 6. 验收
- 主要目标 430×932 / 932×430（iPhone 14 Pro Max），加验 320 / 375 / 390 宽、竖屏 + 横屏；无横向溢出，数字不贴边，选段的正常操作无需滚到屏幕外。
- 桌面 1024×768 / 1440×900 / 1920×1080 / 2560×1440：铺满无大片空白，回放页不出现整页滚动条，快捷键可用。
- iPhone 主屏 PWA 启动：安全区、状态栏、键盘弹出时弹层位置。
- 单击入点/出点一次生效；松手后时间不漂移。
- 任务列表在 SSE 更新时不跳回顶部。
- `npm test` 全量通过，并实际启动服务看浏览器控制台无报错。


### 回放与设置细节补充

- 通道与日期只在视频外的选择行显示一次。视频内以图标和无障碍标签表达播放状态，回放时显示回到直播图标；不以录像画面冒充直播。
- 传输控件图标 26px，10 秒字样居中；播放状态不独占视频下方一行。
- 设置弹层锁定背景滚动，内容自行滚动；关闭后回到原页面位置，顶部关闭图标不因初始焦点自动出现圆环。
- 四页页头的刷新复用同一组件及同一外观，执行“重新加载应用”并保留当前页签。账户或配置弹层内的刷新仍只更新就近数据，反馈显示在当前弹层。

- iOS 安装模式按 design-system §9 保留统一大视口高度。顶部标题在真实安全区之后另避让至多 20px 系统渐隐带，同时减少有界内容区高度，禁止移动底栏或再减整页高度。固定背景与状态栏 meta 均不是关闭系统模糊的保证；Chromium 几何模拟不代表真机视觉已通过。
