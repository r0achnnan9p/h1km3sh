# 设计系统（Foundation）

本仓库 Web 控制台的**长期设计约束**。任何 UI 改动（人或 AI）开工前必须先读本文件。

## 0. 文档关系与优先级

| 文件 | 管什么 | 变化频率 |
|---|---|---|
| `docs/design-system.md`（本文件） | 原则、Token、组件、交互、断点、文案、禁止清单 | 很少变 |
| `docs/ui-glass-spec.md` | 每一屏的具体布局和尺寸（手机 + 桌面） | 改版时变 |
| 设计画布（`docs/design/*.png` 为导出截图） | 视觉参照 | 改版时变 |
| `docs/ui-build-steps.md` | 分步施工提示词 | 施工期间 |
| `public/console.css` 的 `:root` | Token 的**唯一代码来源** | 随本文件变 |

冲突时的优先级：本文件 > `ui-glass-spec.md` > 画布截图 > 现有代码。现有代码和规范不一致时，以规范为准改代码；规范本身说不清时，**停下来问**，不要自己发明新样式。

## 1. 原则

1. **只为一个人设计**。没有新手引导、营销文案、长说明。
2. **图标优先**。按钮默认只有图标；中文写在 `aria-label` 和 `title` 里。允许写字的例外见 §10。
3. **一次点击就有确定结果和即时反馈**，不依赖悬停、不要求双击；提交后留在原页，用提示条反馈，不跳页。
4. **数字一律等宽**（时间、时长、速度、大小、百分比、计数）。
5. **深色底 + 玻璃浮层**。玻璃只用于浮在内容或背景上的控制层。
6. **移动优先，桌面增强**。手机（iPhone 主屏 PWA）是主场景；桌面要**铺满整屏**，多出来的空间用来放更多信息和更精细的时间轴，不做居中窄版。

## 2. Token

唯一代码来源：`public/console.css` 的 `:root`。**`:root` 以外不得出现彩色色值、阴影、模糊、圆角数字**（中性透明度例外见 2.2）。新增 Token 要先改本节，再改 `:root`。

## 3. 字体与字号

- 文字：`--font`（系统字体，中文 PingFang SC / 微软雅黑）。不使用 Inter、Roboto 或任何 CDN 字体。
- 数字：`--mono`（`public/fonts/jetbrains-mono.woff2` 本地加载），并加 `font-variant-numeric: tabular-nums`。
- 字重只用 400 / 600 / 700。

| 级别 | 字号 | 用途 |
|---|---|---|
| badge | 11–12 / 700 mono | 数量角标 |
| caption | 12–13 | 次行信息、日期分组标签、表单标签 |
| body | 15（桌面）/ 16–17（手机） | 列表名称、入出点时间 |
| title | 20 | 桌面区块标题、时长 |
| figure | 22 | 进度百分比 |
| display | 28 | 时间轴当前时间 |
| hero | 36 | 拖动时的时间牌 |

## 4. 颜色语义

- 强调色 = 能点、已选、正在进行。不要拿它做装饰。
- 绿 = 完成 / 在线 / 有录像；琥珀 = 需要你处理 / 缺口 / 待核实；珊瑚红 = 失败 / 危险 / 离线。
- **状态必须同时有图标**（✓ / ! / ⚠），不能只靠颜色。
- 强调色和绿色亮度接近，同时出现时靠形状区分（进度条 vs 录像段条）。

## 5. 玻璃层级

| 层 | Token | 用于 |
|---|---|---|
| L1 主玻璃 | `--glass` + `--glass-blur` + `--glass-shadow` | 时间轴面板、导出栏、活动任务卡、视频上的胶囊 |
| L2 次级 | `--glass-light` | 桌面导航、列表组、页签、桌面侧栏、桌面侧面板；手机 Precision 原型的成片/设置/历史任务改用透明分隔行，页签用下划线，底栏按导航组件规格 |
| L3 提示 | `--glass-strong` + `--glass-prompt-*` | 提示条、放大镜、底部弹层、桌面模态 |
| 内嵌控件 | `--fill-control`（无 blur） | 玻璃里的按钮 |
| 凹槽 | `--fill-well`（无 blur） | 分段控件底槽、输入框 |

规则：同一屏玻璃层 ≤ 4；**玻璃里面不再套带 blur 的玻璃**；`prefers-reduced-transparency: reduce` 或不支持 `backdrop-filter` 时退为 `--surface` 实色。

## 6. 图标

- 唯一来源：`public/ui-primitives.js` 的 `ICONS`。新图标**必须加到这里**，用 `iconSvg(name)` 渲染，不在别处内联 SVG。
- 24×24 视框，描边 `currentColor`，`stroke-linecap/linejoin: round`；20–26px 用描边 1.8，14–18px 用 2–2.4。
- 尺寸：列表/工具 20，按钮 22–24，主按钮与手机导航 26。
- 图标按钮必须有 `aria-label` 和 `title`。
- 现有名称：camera fullscreen clock warning mark-in mark-out clear check volume-on volume-off skip-back skip-forward download upload more add edit sort-newest sort-oldest search logout calendar chevron refresh。
- 需要补充（路径见附录 A）：play pause dvr mediamtx cloud tv trash key disk plug retry bolt error-circle check-circle chevron-left chevron-down nav-replay nav-library nav-tasks nav-settings。

2026-10-09 Precision 手机原型变体：日常回放主播放按钮48高，入/出点54高，导出52高、宽40%且至少112；时间轴分区间距6。短屏仍保留44px以上命中区并允许内容区滚动。手机成片、设置与历史任务为透明分隔行，设置图标24、页签为青色下划线；配置弹层、活动任务和桌面仍用上述已登记玻璃组件。以上复用既有Token，不新增视觉Token。

2026-10-17 用户选定的「专注回看」原型：桌面和手机共用同一份回放 DOM；来源、通道和日期放顶栏，日期两侧为单箭头，24px 图标 / 44px 命中区。播放三键、当前时间、声音和全屏聚在视频下方。观看 / 选段复用分段控件；选段时每个边界使用一组「44px 标记动作 + 可点开的精确时间」字段，清除与导出同排，均至少 44px 高。采用现有字体、颜色、圆角与间距 Token。

手机目标为 iPhone 14 Pro Max 的 430×932 与 932×430 CSS 视口，并预留安全区；正常竖屏收紧到一屏内，较窄 / 较短屏允许正文滚动。横屏及全屏将顶栏和下方操作面覆盖于画面边缘，闲置 2.5 秒统一隐藏，选段或暂停也可隐藏；第一次触摸只唤醒。拖动、长按、弹窗、输入及键盘焦点期间保留控件。退出横屏恢复正常布局，模式与入出点不变。 单击播放画面可立即隐藏控制面，下一次点按只唤醒；手动隐藏不会被鼠标悬停提前撤销。普通竖屏与桌面收起控制面后，将空间还给视频。打开入点、出点或播放定位的时间输入框时，在原始点击中同步全选已有时间；输入过程不重新抢焦点或全选。

缺口只在导出确认框展示，每条独立列起止时间和持续时间，不重复顶部日期；跨午夜用「次日」标识。确认框仍复用公共弹层，不新增警告按钮。四页刷新按钮复用同一 DOM 生成函数及 `.app-reload` 外观。

**同一种用途只能有一种组件**。需要新组件时，先在本节登记（必要时先在画布补稿），再写代码。

## 8. 交互与动效

- 按下反馈 < 100ms；过渡用 `--dur-fast`（按下、悬停）/ `--dur`（展开、切换）/ `--dur-slow`（弹层），曲线 `--ease`，不用弹跳。
- `prefers-reduced-motion: reduce` 时去掉位移动画，只保留透明度变化。
- 禁止整页缩放（双击 / 双指）；保留正常滚动、表单输入和时间轴手势（详见施工手册第 2 部分）。
- 全局不可选中文字，输入框恢复可选。
- SSE 刷新不得重置滚动位置、展开状态或已加载条数。

## 9. 断点与输入方式

### iOS 主屏幕 PWA 的视口边界

- `--app-viewport-height` 是布局状态变量，不是视觉 Token。默认 `100dvh`；仅 `navigator.standalone === true` 的窄屏使用 `100lvh`（回落 `100vh`），外壳、回放和列表共用它。不得硬编码屏幕高度或叠加顶部安全区补偿。
- iOS 安装模式外壳使用显式高度、绝对定位，避免固定定位外壳被 WebKit 的偏短布局视口裁剪；内容仍在 `.workspace-main` 内滚动。普通浏览器、桌面和原生全屏不改高度策略。
- 顶部纯色层只绘制安全区背景，不保证关闭 iOS 的系统渐隐。iOS 27 安装模式的首屏文字另用 `--status-bar-blur-gap` 避让，复用 `--space-5`，范围 0–20px；真实安全区为零时避让为零，不修改 `--safe-top` 或全屏高度。四页顶部内边距和有界内容区高度必须成对加减，底栏位置不变。
- 已知 Safari Version 小于 27 不启用避让；安装式 WebView 缺少 Version 时采用有界避让，不拿冻结的 iPhone OS 字段断言系统旧版本。普通浏览器、桌面、原生全屏保持零避让。诊断文字与关闭按钮共用该偏移。
- 键盘弹层继续使用 `fitDialogViewport()`，不拿键盘的可见高度改写整个应用高度。安全区仅用于内容避让及底栏内部填充。
- 浏览器只能验证布局与命中关系；避让是否足够必须由 iOS 主屏幕 PWA 真机验收，不宣称网页关闭了系统模糊。


| 档 | 条件 | 布局 |
|---|---|---|
| 手机竖屏 | 宽 < 760 | 回放目标 430×932；同时验证 320 / 375 / 390 / 430 |
| 手机横屏 | `orientation: landscape` 且高 ≤ 540 | 视频全屏 + 底部玻璃条（spec §3.3） |
| 中屏 | 760–1023 | 手机布局，内容最大宽 640 居中，底部导航 |
| 桌面 | ≥ 1024 | 左侧导航条 + 多栏，**铺满整屏**（spec §3.10） |

- 桌面铺满规则：内容区不设 `max-width`；回放页整屏高度不滚动，视频区占满剩余空间（视频本身 `object-fit: contain`），时间轴横跨全宽；列表 / 网格按宽度自动增减列数；侧面板宽度用 `clamp()` 随屏幕变化。
- 细指针（`pointer: fine`）：可以有悬停态、`title` 提示和快捷键，控件可以收紧到 40；但**必要操作不能只在悬停时出现**。
- 粗指针：不依赖悬停；命中区 ≥ 44。

桌面快捷键（回放页；焦点在输入框时不生效）：

| 键 | 作用 |
|---|---|
| 空格 | 播放 / 暂停 |
| ← → 或 , . | 后退 / 前进 10 秒 |
| I / O | 以当前位置设入点 / 出点 |
| Esc | 清除入出点（有弹层时先关弹层） |
| 1 2 3 4 | 时间轴 30s / 5m / 1h / 24h |
| F / M | 全屏 / 静音 |
| /（成片页） | 聚焦搜索 |

时间轴或边界滑块取得焦点时，保留控件本身标明的微调单位（精细轴 1 秒、Shift 10 秒；全天概览 1 分钟），不再同时触发全局 10 秒跳转；重复按键事件不连发。

## 10. 文案

- 界面语言中文。按钮默认只有图标；用户选定的回放原型中，观看 / 选段、入点 / 出点、清除与导出保留短文字，方便识别。
- 允许出现文字的地方：页面或区块标题（仅桌面）、表单标签、表单按钮（“测试”“保存”）、来源分段（“录像机”“MediaMTX”）、日期分组、错误提示、确认框。
- 错误提示一句话：发生了什么 + 怎么办。
- 术语统一：录像机（界面不写 NVR/DVR）、MediaMTX、189（不写“天翼云盘”“云盘”）、B站、成片、入点、出点、导出、上传、缓存。

## 11. 产品语义（不能被视觉改版破坏）

- 播放位置、请求定位和导出范围是三种不同语义；切换预览不得清除已选导出范围。
- 直播不显示旧的历史播放指针；连接中、暂停、结束、失败不能标成直播中。
- SDK 时间精度未知时要如实标示，不能推算成精确帧时间。
- 保留手填精确时间的编辑入口。

## 12. 禁止清单

- 浅色背景、白色卡片、旧主题遗留颜色（如 `#fff4f5`、`#e9edf0` 一类）。
- `:root` 以外的彩色色值、自定义阴影、3–8px 小圆角。
- Inter / Roboto / CDN 字体；emoji；渐变文字。
- 玻璃套玻璃（嵌套 blur）、同屏超过 4 层玻璃。
- 只有悬停才出现的必要操作；必须双击才生效的操作。
- 提交后跳页；长段说明或教学文案。
- 只靠颜色表达状态；成片列表的已上传状态可使用绿色服务图标／字标，必须同时保留 title、aria-label 和详情文字；异常状态仍有警告图标。
- 散落的内联 SVG（必须进 `ICONS`）。
- 新造一种弹窗 / 按钮 / 列表样式（先在 §7 登记）。
- 桌面居中窄版、给内容区加 `max-width` 留大片空白。
