# H1kM3sh 控制台设计系统

本控制台用于回看录像、精确选段、管理成片与跟踪任务。主要使用场景是从 iPhone 主屏幕启动，桌面使用相同的数据和交互模型。各页布局与验收场景见[各屏规格](ui-glass-spec.md)。

## 颜色、字体和组件

控制台主题定义在 `public/console.css` 的 `:root`。页面和组件引用语义变量；更新主题时同步独立文档的 `lib/standalone-ui.js` 和主屏幕启动颜色。独立授权与结果页面内嵌样式，以便在各自的内容安全策略下渲染。

| 设计元素 | 变量 | 用法 |
|---|---|---|
| 工作区与面板 | `--bg`、`--surface`、`--surface2` | 深墨色背景、实色内容面板、次级控件或抬高的表面。相邻面板用 `--line` 分隔 |
| 文本 | `--text`、`--muted`、`--dim` | 标题、主要操作和时间优先。使用次色显示来源、日期、文件大小及帮助文字 |
| 操作与选中 | `--accent`、`--on-accent`、`--tint` | 青色主按钮配深色文字。选中项用浅青底、当前项指示或下划线 |
| 业务状态 | `--green`、`--warning`、`--coral` | 有录像／完成、需处理、错误／删除。状态同步使用文字、可理解的图标或读屏名称 |
| 尺寸 | `--space-*`、`--control*`、`--radius-*` | 常用触控目标至少 44px，细指针辅助工具可以用 40px。面板、卡片、输入框和角标各用对应的圆角 |
| 正文与数字 | `--font`、`--mono` | 正文用本机系统字体，控制台时间、时长、传输数据用本地 JetBrains Mono 或等宽后备字体 |
| 历史样式名称 | `--glass`、`--glass-light`、`--glass-strong` | 复用实色表面。浮在视频上的控件仍需保证画面变化时的对比度 |

当前基色为背景 `#0b1118`、面板 `#151e28`、次级表面 `#202e3b`、正文 `#edf4f7`、次要文字 `#b0c1cc`、操作青 `#81e5e0`。区块依靠间距、分隔线和标题组织。正文避免外部字体请求。可操作图标集中在 `public/ui-primitives.js` 的图标注册表，通过 `iconSvg()` 渲染。

| 组件 | 交互约定 |
|---|---|
| 导航 | 手机底栏、桌面侧栏都显示图标和中文名称。当前页有选中态和 `aria-current`，任务角标来自实际活跃任务数 |
| 按钮与分段 | 主要提交有明确文字。传输、日历、刷新等熟悉的操作可用图标，提供明确的 `aria-label` 和提示。键盘焦点清晰，必要操作常驻可达 |
| 列表 | 长名称可换行或省略并从详情查看全名。数据刷新保留已加载记录和滚动锚点。区分无数据、无匹配、等待和请求失败 |
| 字段与功能反馈 | 显示字段名。确认前展示影响；提交中锁定重复操作，错误保留在当前表单。支持中文输入法，候选词确认不触发表单提交 |
| 提示条 | 导出或上传入队后留在当前页。提示区提供范围或文件名与“查看任务”入口。隐藏时其中的按钮退出焦点序列 |
| 动效 | 按下、切换和显示反馈使用短过渡；遵循 `prefers-reduced-motion`。降低透明度时保留实色表面 |

## 原生弹层与桌面详情

同类弹层使用 `openDialog()`。用独立标题 ID 建立无障碍名称，有说明时关联说明。普通弹层的初始焦点落在标题，危险确认优先聚焦取消或保留连接。原生 dialog 限制背景交互，配合锁定页面滚动；最后一个弹层关闭后恢复打开前的位置与焦点。替换弹层时，旧弹层的关闭回调不能抢走新焦点。

手机窄屏使用底部面板。标题与操作栏分隔，较长的正文独立滚动；短横屏与大字下仍允许滚动到所有操作。使用 `visualViewport` 将弹层放在可见区域，键盘弹出时滚动被遮挡的字段。日期、定位、选段、上传账号和危险确认共用同一套容器。桌面设置首层详情直接进入右栏，编辑或确认继续使用居中对话框。

关闭按钮或 Esc 处理关闭。手机可从标题区域明确下拉；列表或表单内的正常滚动不触发关闭。有未保存修改时先提示，再由用户明确放弃；连续向下拉不能丢弃草稿。提交期间保护在途操作。原生全屏时提示、拖动读数及对话框继续可见、可交互。

## 安装模式与布局边界

- 使用相对 `start_url` 与 `scope`、`display: standalone`、Apple touch icon 和 `viewport-fit=cover`，兼容根路径和带部署前缀的控制台。主屏启动颜色与页底一致。
- `--app-viewport-height` 默认为 `100dvh`。iOS 窄屏安装模式的外壳使用显式高度与绝对定位，使用 `100lvh` 并保留 `100vh` 回退。正常内容滚动在工作区内。原生全屏、放大状态和普通浏览器仍使用各自的视口逻辑。
- 刘海、底部主屏指示条和横屏两侧用 `--safe-*` 避让。iOS 27 安装模式的状态栏渐隐另用 `--status-bar-blur-gap` 在真实安全区之后避让 0–20px，标题增加的留白从有界内容区扣除；底栏位置保持稳定。已知 Safari 版本低于 27 时不启用，独立 WebView 缺少版本号时使用有界避让。
- 播放控件、时间尺、导航拖动分别处理各自的手势。保留移动端已有的防误缩放、输入区文字选择和纵向滚动行为。键盘的可见高度只影响弹层，不覆盖整个应用高度。
- 宽度 760–1023px 使用底栏与适度收束的内容区。1024px 起提供固定左侧导航，正文使用剩余宽度。回放视频完整呈现，设置与任务使用并行面板。短横屏优先给录像画面留空间。
- 浏览器缩放与视口模拟可检查断点、滚动和遮挡；iPhone 主屏幕冷启动、WebKit 键盘、Home 指示条与系统渐隐须在真实设备验收。

## 快捷键与录像语义

| 场景 | 操作 |
|---|---|
| 回放 | 空格播放／暂停，左右键或逗号／句号前后 10 秒，I／O 标记边界，1–4 切换时间尺窗口，F 切换全屏，M 静音 |
| 时间尺获得焦点 | 方向键微调 1 秒，Shift 加方向键微调 10 秒，不叠加全局跳转 |
| 退出 | Esc 优先处理弹层与全屏，普通回放清除已选边界 |
| 成片与任务 | 成片页按 / 聚焦搜索。手机任务页签支持方向键和 Home／End |

输入字段和弹层内优先使用自身键盘行为。播放位置、请求定位、导出范围分别保存。定位或切换预览不得隐式修改边界；时间精确到秒，设备未报告的逐帧精度不作推断。直播、回放、暂停、结束和失败均根据播放器状态显示。

样式回归由 `test/design-tokens.test.js` 检查控制台 CSS 的令牌、外部字体与前端图标来源。改动还应通过与页面相关的交互测试和真实浏览器检查；各屏验收入口见[各屏规格](ui-glass-spec.md)。
